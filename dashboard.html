    All figures on this page are simulated demo data for prototype review. They follow the metric list in the CortexAI monitoring dashboard specification and are generated from a seeded model shaped to be plausible for the Kyrgyz Republic, so regions genuinely differ from one another and every filter recomputes the page. No production traffic is represented.
    Demographics are aggregate-only by design: the platform never displays or exports an individual citizen profile. Agency views are scoped, so in production an agency sees only the rows belonging to its own services.
    Palette validated for dark-surface contrast and colour-vision deficiency. Every chart has a matching data table under the “Data tables” toggle.
